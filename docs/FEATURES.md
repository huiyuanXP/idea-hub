# 点子工坊功能

## 账户与工作区

- 使用本机创建的账户登录，浏览器 session 到期或退出后清除当前页面的私有状态。
- 将业务记录保存在本地 SQLite，并通过修订冲突与历史快照保护已有内容。
- 从当前账户的点子、Plan、Ticket 和已登记 workspace 汇总统一项目目录，供侧栏、筛选、表单与连接管理选择，历史和手工执行快照不新增项目。
- 详情关闭或切换前确认未保存修改，限制弹窗键盘焦点并在关闭后恢复入口焦点。
- 按项目筛选工作区中的点子、Plan、Tickets、归档和执行记录，侧栏与指标计数也只统计所选项目，切换项目或视图时立即重新读取，后台每 3 秒刷新一次。
- 顶部指标可用鼠标或键盘点击，分别进入点子收件箱、筛选为待推进或已完成的看板和待我处理，计数只统计所选项目并与目标视图采用同一状态口径。

## 点子收件箱

- 点子只需填写原文、项目和优先级，标题取自原文首行，并为当前修订创建持久规划请求。
- 快速点子的项目下拉与侧栏、筛选共用同一项目选择，在任一处选定后点子保存到该项目；所有入口只列出真实项目，首次加载、重新登录和点击品牌链接时默认选中通用，各视图只显示所选项目的记录。
- 收集点子后列表立即刷新并切换到点子所属项目，新点子马上可见。
- 快速点子与点子、Plan、Ticket 表单使用同一个项目选择器，可选任一已有项目或新建项目。
- 修改点子会产生新修订和规划任务，同时保留旧计划及其来源信息。
- 未接入规划 Agent 时，在点子卡片提示接入所属项目或手工整理，并将项目带入接入表单。
- 用简短状态展示规划进度、失败原因、冷却与可用重试，将租约及投递诊断放入规划详情。
- 默认阅读点子全文并查看带来源修订标识的关联计划，明确编辑后才修改内容。

## 规划工作台

- 展示目标、范围、验收、假设和与原始点子的关联。
- 使用项目 Agent 的专属领取 token 原子回写 Plan 和最多三十个稳定逻辑 key 的 Tickets。
- 默认按要解决的问题、完成标准和拆分任务阅读 Plan，补充字段与来源历史可展开。
- 浏览最多三十个关联 Tickets 的完整标题、状态和目标，从任务返回保留原 Plan、列表滚动与筛选。
- 从已保存 Plan 手工创建继承目标、范围、验收和执行约定的新 Ticket。

## Ticket 看板

- 默认按做什么、怎样算完成和当前进度阅读 Ticket，将等待原因与完成证据直接显示。
- 显式编辑全部既有字段，完成证据缺失时定位输入，保存失败或修订冲突保留草稿。
- 用看板或列表查看待开始、进行中、等待、完成和错误任务，并按推荐执行顺序、优先级、创建或更新时间稳定排序。
- 推荐执行顺序由确定性规则计算，依次排列可执行、进行中、等待处理、等待前置和已完成任务，同层按未满足依赖数、可解锁任务数、优先级和创建时间排序，并在卡片上标注原因。
- 状态筛选除单一状态外提供合并待开始与进行中的“待推进”。
- 看板列跟随真实执行状态：批准开发、Agent 领取或 Docker 运行时进入进行中，开发交付或手工标记等待验收后进入已完成并带“等待审核”标签，当前修订开发失败时进入异常。
- 已完成列中等待审核的卡片可直接审核通过，通过后 Ticket 自动归档并移出看板。
- 使用鼠标、触屏手柄、键盘列选择或等价菜单打开同任务执行/验收，或明确确认手工状态，几种方式效果相同；拖动本身不启动执行。
- 执行面板以两个可切换的选项卡说明本机 Agent 开发与固定 Docker 操作的用途和区别。
- 详情通过“执行此任务”进入精确修订绑定的共享面板；所有相关 workspace Run 分页均读取，历史修订的结果保留。
- 空看板先提供从点子开始或创建 Ticket 的真实入口，执行申请、进度和验收放在任务内容之后，固定 Docker 操作按需展开。
- 为指定项目 workspace 申请开发执行，冻结 Ticket 修订与期限并记录批准或拒绝。
- 为登记的固定 Docker 操作单独申请资源预算和范围受限的执行授权。

## 待我处理

- 汇集需要澄清、审批、验收或外部条件的 Tickets。
- 查看本机开发任务的待批准、失败和待验收结果，并执行批准、取消、验收或返工操作。

## 归档

- 审核通过（状态为完成）的 Ticket 只在归档视图中按项目存档展示，可查看详情与证据但不能重新申请开发。

## 执行记录

- 保存手工执行快照的冻结 Ticket 和填写的证据，同时明确标记它是手工记录。
- 展示真实本机开发 Run 的进度、Agent 总结、实际 diff、修改文件及测试命令和退出码。
- 在 Ticket 执行面板中以 CLI 风格的实时控制台按步骤显示 Agent 消息、推理、命令及可折叠输出、文件变更、工具调用、错误和结果。
- 控制台通过本地 SSE 在约 2 秒内推送新条目，连接失败时回退到游标轮询，并支持跟随滚动、暂停跟随和复制全部。
- 已结束的 Run 可从 SQLite 完整回放转录，超出单条或总量上限时明确标注截断而不会让 Run 失败。
- Run 所有者可在运行期间发送「引导」或「打断并发送」消息，并在转录中看到其已排队、已送达、已应用或已拒绝状态。
- 输入框按 runner 实际上报的能力禁用不支持的方式，Run 结束后禁用，服务端对非运行中的提交返回 409。
- 原阶段日志保留为默认折叠的「阶段日志」。
- 保留固定 Docker 后端的真实状态、签名结果、取消与停止收据以及受限产物下载。
- 在 owner 审核通过开发结果后将 Ticket 标记完成并归档，同时保留先前的修订和执行证据。

## 连接与执行

- 为指定项目和能力生成短期一次性安装授权码。
- owner 可通过本地接口发放、查看与撤销 Run 专属短期 Worker，独立 machine MCP 提供两个委派 Run 查询与六个租约动作；原生 consumer 采用私有 journal/flock、请求前持久化和稳定重放；真实 Docker 验收由专用 fixture 与 CI 分别记录。
- 点击下载独立的 MCP/CLI 客户端包，或读取网页和 JSON 安装指南。
- 安装器将项目关联到工坊并写入增量 MCP 配置，不覆盖其他连接。
- 使用 STDIO MCP 提交点子或 Ticket，以及读取、领取和回写被授予的本项目任务。
- 具有 submit 能力的项目客户端按修订更新 Ticket 状态并有界追加调用方证据，通过同事务历史与请求身份保护重试、冲突和运行占用。
- MCP 查询按完整 4 MiB UTF-8 双表示响应预算分页，客户端包更新后使用有界流式读取和多字节安全 STDIO。
- 常驻 Agent 使用 outbound 请求领取任务并发送心跳，模型认证保留在安装机器上。
- 常驻 Agent 可通过 Codex 本机配置/Profile、Codex 账户登录、本机已登录的 Claude Code CLI 或 OpenAI 兼容的直接 API Call 完成规划与开发，API 密钥只从本机环境变量读取。
- 查看注册客户端的项目、版本、能力、最近通信、接入方式与模型/端点、就绪状态，以及约五条可见、其余滚动查看的近期事件。
- 心跳与 MCP 调用只刷新最近连接状态，仅在首次连接、超过离线阈值后重连或就绪状态/错误改变时记录事件。
- 区分 MCP 最近使用、常驻进程在线、延迟、离线和已撤销状态。
- 撤销客户端后拒绝后续工具调用、任务领取和续租，同时保留连接历史。

## 后台机制

- 本机进程定时维护规划投递、失效租约与有限恢复，而不依赖浏览器持续打开。
- 通过本地账户和项目专属客户端身份隔离数据，拒绝伪造身份及跨项目访问。
- 通过批准范围、修订绑定、有限租约和受管进程记录约束本机开发执行。

priority、queue、budget、cadence 等可填写文本字段仅在对应执行或调度接口明确使用时构成实际运行约束。
